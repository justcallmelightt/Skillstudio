Skill Studio 안내

Skill이란?

AI에게 매번 다시 설명하던 작업 방식을, 다음에도 꺼내 쓸 수 있도록 정리한 지침입니다.

파일 하나에서 시작해요.

Skill의 중심은 SKILL.md라는 문서입니다. 어떤 일을 맡길지, 언제 사용하면 좋은지, 어떤 순서와 기준을 따라야 하는지를 적습니다. 필요하면 참고 자료나 스크립트를 같은 폴더에 더할 수도 있어요.

예를 들면

“코드 리뷰할 때 추측은 빼고, 재현 가능한 문제와 근거부터 찾아줘.”

이 작업 방식을 Skill로 저장해두면 다음 리뷰에서도 다시 활용할 수 있습니다.

Skill 사용 예시

반복 설명은, Skill 이름 하나로.

같은 일을 요청할 때, Skill을 쓰기 전과 후를 비교해보세요.

Skill 없이 매번 기준을 다시 설명

이 화면의 정보 계층과 간격을 다듬고 실제 UI에 반영해줘. 먼저 화면 목적과 사용자를 살펴보고, 색상과 타이포그래피를 정리해줘. 버튼을 누를 때 반응이 있는지, 글자 대비가 충분한지 확인하고 모바일과 키보드 사용도 점검해줘.

✳

색상과 간격을 조정했어요. 버튼 상태와 모바일 화면은 아직 반영하지 않았어요.

버튼 반응도 실제로 구현해줘. 누를 때 바로 반응해야 해.

✳

버튼에 마우스를 올렸을 때의 효과를 추가했어요.

마우스를 올릴 때만 바뀌고 누를 때는 반응이 없어. 모바일 레이아웃도 여전히 깨져 있어. 빠진 부분까지 구현하고 확인해줘.

✳

눌림 상태와 모바일 레이아웃까지 반영하고 확인할게요.

Skill 없이 매번 기준을 다시 설명

이번 코드 변경을 검토해줘. 변경 목적과 영향받는 파일을 먼저 확인하고 기존 동작과 비교해줘. 문제를 찾으면 재현 조건과 코드 근거를 함께 적어줘. 확인하지 못한 추측이나 스타일 취향은 결함처럼 단정하지 말고 중요도순으로 알려줘.

✳

코드 스타일과 변수 이름부터 정리했어요.

스타일보다 실제 동작의 문제를 봐줘. 기존 동작과 비교하고 코드 근거도 함께 적어줘.

✳

문제가 의심되는 부분을 찾았어요.

추측만으로는 판단하기 어려워. 재현 조건을 확인하고, 확인된 문제만 중요도순으로 알려줘.

✳

재현 조건과 근거를 다시 확인해 보고할게요.
