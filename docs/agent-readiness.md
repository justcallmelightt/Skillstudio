# Skill Studio 에이전트 도입 준비

상태: 설계 초안. 이 문서는 에이전트가 이미 연결되었거나 설치·실행 검증이 가능하다는 뜻이 아니다.

## 현재 확인된 상태

- 정적 HTML/CSS/JavaScript 앱이다. AI 요청을 처리할 서버나 인증 흐름은 없다.
- 사용자가 폼을 채우면 브라우저에서 `SKILL.md`를 생성하고 미리보기·복사·다운로드한다.
- 초안과 테마는 브라우저 `localStorage`에 저장된다. 현재 완성도 점검은 필드의 유무·형식만 확인하며 실행 결과를 검증하지 않는다.
- Codex와 Claude Code 사용 위치는 안내하지만 자동 설치하지 않는다.

## 제안하는 에이전트의 책임

사용자가 원하는 작업 방식을 짧게 설명하면 에이전트가 필요한 사항만 되묻고, 상시 프로젝트 규칙과 상황별 반복 작업을 구분한다. 사용자가 승인한 내용으로 초안을 만들고 기존 편집기의 필드와 미리보기에 반영한다. 사용자는 에이전트가 쓴 각 항목을 직접 수정하고 되돌릴 수 있어야 한다.

`AGENTS.md`는 프로젝트에 지속 적용할 규칙, `SKILL.md`는 특정 요청에 사용할 작업 절차로 분리한다. 같은 원칙이 두 파일에 중복될 때는 이유를 설명하고 한쪽으로 옮길 수 있게 한다. 제품별 형식과 적용 위치는 검증된 어댑터만 제공하며, 단순히 파일명만 바꿔 호환된다고 표시하지 않는다.

## 확인 결과의 표시 기준

1. **형식 확인**: 필수 정보, 파일 구조, 이름, 빈 항목을 검사한다. 모델 호출 없이 가능하다.
2. **시나리오 시험**: 사용자의 예시 요청으로 지침을 적용한 응답을 관찰하고 기대 동작과 어긋난 점을 설명한다. 실제 모델 실행이 없으면 `예상 검토`로만 표시한다.
3. **환경 확인**: 사용자가 지정한 제품과 프로젝트에서 파일이 실제로 적용·호출되는지 확인한다. 연결과 권한이 없으면 `확인하지 않음`으로 남긴다.

에이전트는 확인 근거, 사용한 환경, 실패한 사례, 아직 확인하지 못한 범위를 보여줘야 한다. 시나리오 시험을 통과해도 실제 프로젝트에 설치되었다고 주장하지 않는다.

## 기존 앱에 연결할 때의 경계

- AI 전송 전 어떤 초안과 프로젝트 정보가 외부로 나가는지 보여주고 명시적으로 시작하게 한다. 자동 저장된 기존 초안은 동의 없이 전송하지 않는다.
- 제공자 API 키는 정적 페이지나 브라우저 저장소에 넣지 않는다. 서버 경계, 인증, 비용·남용 제한, 실패 시 재시도 정책을 먼저 정한다.
- 응답을 기존 폼에 쓰기 전에 스키마와 길이를 검증한다. 기존 초안은 덮어쓰기 전 보관하고 되돌릴 수 있게 한다.
- 사용자가 제공한 저장소 파일과 모델 응답은 지시가 아닌 데이터로 취급한다. 에이전트가 읽거나 변경할 범위와 도구 권한을 제한한다.
- 자동 설치는 별도 기능이다. 브라우저만으로 사용자의 로컬 프로젝트에 임의로 쓰지 않으며, 파일 변경 전 경로·차이·승인을 보여준다.
- `README.md`와 `SECURITY.md`는 실제 네트워크 전송·보관 정책이 정해지고 구현될 때 함께 갱신한다. 지금의 로컬 전용 설명을 미리 바꾸지 않는다.

## 첫 구현 전 결정할 것

- 첫 대상은 어떤 제품/환경인가? (예: Codex 로컬 프로젝트, Claude Code 로컬 프로젝트)
- AI 제공자와 서버 실행·호스팅 방식은 무엇인가? 사용자가 직접 키를 넣는 방식은 기본값으로 두지 않는다.
- 첫 버전의 끝점은 `초안 생성 + 형식 확인`인가, `시나리오 시험`까지인가? 실제 환경 확인·자동 설치는 연결 방식이 정해진 뒤 별도 범위로 잡는다.
- 성공 기준은 무엇인가? 짧은 요청으로 초안 작성, 원본 보존·되돌리기, 검사 근거 표시, 네트워크 오류 시 수동 편집 유지 여부를 시험한다.

## 권장 구현 순서

1. 기존 폼과 Markdown 생성기를 재사용할 수 있도록 데이터 모델과 검증 함수를 분리한다.
2. 사용자 승인 후에만 에이전트에 요청하고, 구조화된 제안을 변경 미리보기로 제시한다.
3. 형식 확인과 예시 요청 시험을 별도로 구현하고 결과의 검증 수준을 명시한다.
4. 제품별 적용 어댑터와 실제 환경 확인은 하나씩 추가한다. 자동 설치는 사용자가 대상·차이를 확인할 수 있을 때만 제공한다.
